# SOC Incident Tracker v1

This project is a simple SOC/NOC operations automation project built using Python and Pandas.

## Features
- Read telecom dataset
- Clean rows
- Generate SOC incidents
- Calculate downtime automatically
- Create Excel report
- Generate summary dashboard

## Tools Used
- Python
- Pandas
- OpenPyXL
- VS Code

## Output
- Incident Report
- Downtime Calculation
- Summary Sheet
