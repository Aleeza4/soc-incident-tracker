# SOC Incident Tracker v1 - Python Operations Automation Project

## Overview

This project is a simple SOC/NOC operations automation system built using Python and Pandas.

The goal of this project is to simulate real-world incident tracking operations by generating incidents, calculating downtime automatically, and exporting professional Excel reports.

This project was created as part of practical learning in operations automation and reporting systems.

---

## Features

- Read telecom dataset using Python
- Clean duplicate and empty rows
- Generate SOC incident records
- Create alarm and close times
- Calculate downtime automatically
- Assign engineers and incident status
- Export professional Excel report
- Generate summary dashboard

---

## Technologies Used

- Python
- Pandas
- OpenPyXL
- Excel
- VS Code
